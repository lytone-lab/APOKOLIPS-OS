## Why GPL v3 for this project

APOKOLIPS is a solo project built in the open. The GPL is a promise:
**whatever grows out of this stays open.** Anyone is welcome to
build on the work — as long as they keep building in the open too.

That's not a restriction. It's a deal. Use my code — but if you
improve it, share the improvement back so the next person can too.

## Companies and commercial use

GPL v3 means a company cannot simply take APOKOLIPS, modify it
quietly, and ship it as part of a closed product. That is
intentional. If a company wants to do that, they must contact
lytone for a separate commercial license.

For everything else — personal use, research, education, hobby
projects, open-source forks, distros, internal tools where the
source is shared — you're free. Go build something.
